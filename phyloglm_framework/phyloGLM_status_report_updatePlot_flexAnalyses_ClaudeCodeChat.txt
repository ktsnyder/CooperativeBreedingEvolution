⏺ Summary of PhyloGLM Analysis Development and Current Status

  Evolution of the Analysis

  1. Initial Development (May 13-14, 2025)
    - Started with scratch phyloglm.R - basic implementation testing
  phyloglm models
    - Evolved to run many phyloglm.R - comprehensive analysis testing
  multiple models with different interactions
    - Key features: Model comparison via AIC, model averaging, bootstrap
  confidence intervals
  2. Visualization Development (June 2, 2025)
    - test_phyloglm_plots.R - Developed visualization approaches including:
        - Forest plots for coefficient comparison
      - Faceted interaction plots
      - Coefficient heat maps
      - Predicted probability plots
  3. Modularization (June 12, 2025)
    - Created run_phyloglm_fxns.R - Comprehensive function library
    - Created phyloglm_execution_code_for_Run_Analyses.R - Execution script
    - Enhanced features: convergence diagnostics, post-hoc tests,
  diagnostic plots
  4. Major Updates (June 16, 2025)
    - Updated functions to accept customizable predictor variables (not
  just cooperative breeding)
    - Added PDF output for all plots
    - Fixed plotting issues with confidence intervals (ribbons instead of
  error bars)
    - Fixed AIC ranking plot variable name display
  5. Latest Development (July 8, 2025)
    - Created phyloglm_summary_figure.R - Publication-quality summary
  visualization
    - Combines forest plots, interaction visualizations, and model
  selection heatmaps

  Current Capabilities

  Analysis Features:
  - Phylogenetic logistic regression with multiple model formulations
  - Tests main effects and interactions between predictors, territoriality,
   and body mass
  - Model selection via AIC with model averaging
  - Bootstrap confidence intervals (configurable iterations)
  - Convergence diagnostics and multicollinearity checks
  - Post-hoc significance tests for stratified effects
  - Marginal effects calculation

  Supported Variables:
  - Response: Female song presence/absence, Cooperative breeding
  - Predictors: Any binary predictor (e.g., cooperative breeding, familial
  living)
  - Territoriality: Multiple classification schemes (WeakVsStrong,
  Territory_12vs3, etc.)
  - Control: Body mass (log-transformed)

  Visualization Outputs:
  - AIC ranking plots with significance thresholds
  - Interaction plots with confidence ribbons
  - Coefficient plots with 95% CIs
  - Effect size plots (odds ratios)
  - Diagnostic plots (predicted vs observed)
  - Combined publication figures

  Key Results from Analysis

  1. Cooperative Breeding → Female Song:
    - Strong positive effect when territoriality is weak/absent
    - Effect diminished or reversed with strong territoriality
    - Significant interaction term in some models (p ≈ 0.056)
  2. Female Song → Cooperative Breeding:
    - Generally positive effects
    - Less pronounced interaction with territoriality
  3. Model Selection:
    - Best models typically include interaction terms
    - Body mass often improves model fit but doesn't change main
  conclusions

  Current File Structure

  Main Functions: run_phyloglm_fxns_updated.R
  Execution Code: phyloglm_execution_code_for_Run_Analyses_updated.R
  Plot Fixes: phyloglm_plot_fixes.R
  Summary Figure: phyloglm_summary_figure.R

  All analyses save outputs to Outputs/PhyloglmResults/ including CSV
  summaries and both PNG and PDF plots.
